### 📦 Featured project: [Why Are 57% of Orders Late?](https://github.com/ganesh-gudala/supply-chain-delivery-analysis)

Analysed **65,752 orders** from a global retailer to find why most deliveries arrived late.

- **Finding:** the problem wasn't geography or season, it was the **shipping promise**. First Class promised 1 day but always took 2, so it was late **100%** of the time.
- **Impact:** $18.1M of revenue came from late orders.
- **Built with:** SQL (CTEs, window functions), Python (pandas), Power BI (DAX)
